# Trees 🌲

A Kotlin implementation of **Tree** data structure with node construction, depth-first and level-order traversal algorithms.

> 📚 Built as a learning project following the **Data Structures & Algorithms in Kotlin** book by Kodeco (Ray Wenderlich).

---

## Features

- 🏗️ **Tree Construction** — build general (n-ary) trees with multiple child nodes
- ⬇️ **Depth-First Traversal** — recursively visit nodes from root to leaf
- 📶 **Level-Order Traversal** — visit nodes level by level using a queue
- 🔍 **Search** — find nodes by value within the tree

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/M0bileDev/Algorithms_and_structures_Trees.git
   ```

2. Run the project:
   ```bash
   ./gradlew run
   ```

> **Note:** The default branch is `develop`.

## Purpose

This project was developed as a hands-on learning exercise to practice general tree fundamentals in Kotlin, covering n-ary tree construction, depth-first and breadth-first (level-order) traversal strategies, and node search operations.
